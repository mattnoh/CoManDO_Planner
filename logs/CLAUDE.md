# logs/

Experimental output generated by running the CoManDO planner.

## Organization
- Subfolders (`circle`, `hardware`, `hover`, `landing`, `relative`) contain CSV recordings of state, command, and solution data for each run, along with PDF analysis files that visualise performance.
- Python scripts (`plot_circle.py`, `plot_landing.py`, `plot_relative_landing.py`, `animate.py`, `analyze_flights.py`) generate visualisations and aggregate statistics from the CSV data.

The logs are timestamped and grouped by scenario, enabling reproducible analysis of the planner’s behaviour across different experiments.
