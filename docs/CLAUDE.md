# docs/

Human‑readable documentation for the CoManDO planner.

## Core guides
- `COMANDO_PLANNER_INTERFACE.md` – Detailed description of the planner’s ROS interface (topics, services, and parameters).
- `dynamic_target_hardware_integration.md` – Instructions for integrating dynamic targets with real hardware (Crazyflie, PX4).

## Tutorial series (`docs/CoManDO_planner/`)
- `01_crazyflie_ros_nodes.md` – Overview of the ROS nodes used with the Crazyflie platform.
- `02_planner_node_setup.md` – Step‑by‑step setup of the planner node, including configuration options.
- `03_mpc.md` – Explanation of the Model Predictive Control implementation, formulation, and tuning.
- `04_debugging_log.md` – How to enable and interpret the planner’s logging and debugging output.
- `05_mathematical_tutorial.md` – Mathematical background of the OCP and MPC approaches.
- `06_online_replanning.md` – Guide to online replanning and handling dynamic targets.

These markdown files provide both high‑level overviews and low‑level implementation details for developers and users.
