# CoManDO_planner

The **CoManDO_planner** is an advanced flight control system that enables drones to perform autonomous maneuvers using **Model Predictive Control (MPC)**. It acts as a *central intelligence* that processes real-time sensor data to calculate optimal future trajectories, allowing the drone to maintain stability during complex tasks like *hovering* and *landing*.
